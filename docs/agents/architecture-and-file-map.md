# Architecture and file map

Core: `__main__.py` (startup, theme, bounded shutdown), `cli.py` (pre-GUI actions: `--version`, `--install/--uninstall-desktop-entry`, `--self-test`, `--terminal-session`; no Qt at import), `_display.py` (git-checkout display version `X.Y.Z+g<commit>`), `desktop_entry.py` (Linux menu entry), `workers.py` (QRunnable worker + signals), `k8s/client.py` (`KubeService`: per-context clients, pagination, loads, `@mutating` writes, overview, watches, metrics, custom resources), `k8s/models.py` (row dataclasses; usage fields `-1` = unknown), `k8s/resources.py` (generic Row, mappers, secret masking, `SPECS`, `CUSTOM_COLUMNS`), `k8s/util.py`.

UI shell: `ui/main_window.py` (navigator/workspace shell, menus, shared settings), `ui/workspace.py` (`ClusterWorkspace`: one cluster's tabs, namespace scope, docks, loading, refresh/watch, actions), `ui/navigator.py`, `ui/resource_table.py` + `ui/table_model.py` (shared table), `ui/detail_panel.py`, `ui/loading_pane.py`, `ui/overview.py`, `ui/theme.py`, `ui/branding.py`, `ui/about.py`, `ui/settings_store.py`, `ui/preferences.py`, `ui/customizations.py`, `ui/environment.py` (macOS PATH), `ui/edit_menu.py`, `ui/status_tone.py`, `ui/status_line.py` (action results held on the status bar), `ui/discard_guard.py` (structured editors ask before discarding edits on Esc, X or Cancel), `ui/activity_log.py` (Logs & activity > Activity: results and complete errors of this session), `k8s`-independent error wording in `ui/load_errors.py` (`describe`: title and sentence for a failure), `ui/wording.py` (plural and count words for messages).

Resource kinds: Nodes, Namespaces, Pods, Deployments, ReplicaSets, StatefulSets are core; `SPECS` adds DaemonSets, Jobs, CronJobs, ConfigMaps, Secrets, Services, Ingresses, NetworkPolicies, PVCs, PVs, StorageClasses, CRDs, Events, HPAs, PDBs, Resource Quotas, Limit Ranges, Priority Classes, webhook configurations, Endpoints, EndpointSlices, Leases and the Access Control group (Service Accounts, Roles, Bindings, ClusterRoles, ClusterRoleBindings). Events, Endpoints, EndpointSlices and Leases have no Edit. Delete (`KubeService.delete_resource`, `DELETABLE_KINDS`) is offered for every listed kind plus Deployments, StatefulSets and ReplicaSets (owner decision, #503; Pods, Nodes and Namespaces keep their own actions), asks Yes/No (default No) and sends the UID precondition. Deleting a CustomResourceDefinition counts its objects, asks once with the count, then lists them in a scrollable dialog and asks again (`ui/crd_delete_dialog.py`); bulk delete of CRDs is refused. Several selected rows show "N selected" in Details with no single-row actions. Custom resource instance tabs are read-only. To offer annotation columns for a kind add it to `customizations.ANNOTATION_KINDS`; for custom resource columns add to `CUSTOM_COLUMNS`.
