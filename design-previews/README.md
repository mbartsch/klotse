# Design previews

Open the HTML file directly in a browser. These pages are visual prototypes with sample data; they are not part of the running Klotse application.

- [Cluster overview concept](cluster-overview.html): compare a dashboard-first overview with a namespace-based cluster map.
- [Resource workspace concept](resource-workspace.html): resource navigation, a filtered Pods table, and a blended details inspector.
- [Workload overview concept](workload-overview.html): workload readiness, resource allocation, attention items, and node capacity.
- [Dialog concept](dialogs.html): a blended YAML editor with review feedback and a clear action hierarchy.
- [All-screens gallery](all-screens.html): clickable mockups for every navigator resource view, insight/tool screen, and the app's major dialogs and workflows. Shared resource kinds use the same table template with kind-specific labels and sample data.
